Source Engine Configurator 0.0.6 is available.

This update refreshes the PowerPC engine configurator package and improves the built-in update check for Leopard systems.

Changes in this update:
- Adds a portable bundled curl-based HTTPS update check.
- Adds a Software Update-style update prompt.
- Adds selectable download sources for Macintosh Garden and GitHub.
- Keeps the configurator self-contained without requiring MacPorts on the target Mac.

Macintosh Garden is the preferred download source for packaged PowerPC builds. GitHub is available for project information, source history, and release tracking.
